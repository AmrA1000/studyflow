Курсовой проект по профессиональному модулю **ПМ07 «Разработка мобильных приложений»**.
Выполнил студент группы **ПО2408** Айткужинов Амир, Колледж ТОО «Astana IT University», 2026.

## Возможности

- **Экран запуска** с анимацией логотипа. Если сессия сохранена, приложение сразу открывает главную.
- **Регистрация** с проверкой всех полей: имя, учебная группа, почта, пароль и его повтор, согласие на обработку персональных данных.
- **Авторизация** по почте и паролю: обработка неверного входа, флажок «Запомнить меня».
- **Главная**: приветствие, прогресс выполнения, ближайшие дедлайны, совет дня.
- **Мои задачи**:
  - добавление, редактирование и удаление задач;
  - отметка выполнения;
  - поиск и фильтры;
  - предмет, срок и приоритет у каждой задачи.
- **Профиль**: данные пользователя, статистика, редактирование имени и группы.
- **Выход** с подтверждением. История экранов очищается, поэтому без повторного входа в закрытые разделы не попасть.

## Технологии

- Flutter, Dart, Material Design 3.
- Без внешних пакетов и без подключения к сети.
- Состояние хранится в `ChangeNotifier` и отображается через `ListenableBuilder`.
- Данные лежат в JSON-файле (`dart:io`, `dart:convert`). В веб-версии они хранятся в памяти.

Проверено на Flutter 3.47 / Dart 3.13: `flutter analyze` не выдаёт замечаний, `flutter test` проходит.

## Запуск

```bash
git clone <ссылка на этот репозиторий>
cd <папка репозитория>
flutter pub get
flutter run            # телефон или эмулятор
flutter run -d chrome  # браузер
```

## Структура

| Путь | Содержимое |
|---|---|
| `lib/main.dart` | всё приложение, разбито на 15 пронумерованных разделов (оглавление в начале файла) |
| `test/store_test.dart` | тесты регистрации, входа, сохранения сессии и проверки ввода |
| `docs/` | пояснительная записка (DOCX и PDF) и скриншоты |
